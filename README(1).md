# Conversor de Planilhas para Excel e Word

Este aplicativo web permite ao usuário fazer upload de arquivos .xlsx ou .csv, realizar formatações automáticas nas descrições, corrigir cabeçalhos e exportar os dados formatados para arquivos Excel e Word.

## Funcionalidades
- Remoção de aspas
- Capitalização adequada de frases
- Cabeçalhos em maiúsculas e substituição de "qtde" por "QUANTIDADE"
- Formatação das colunas F e G como moeda
- Exportação para arquivos .xlsx e .docx

## Como usar
1. Faça upload da planilha (.xlsx ou .csv)
2. Faça o download do Excel e Word formatados
